## 固定计算与可重算读出

inputs.json 与检查代码在首次数值运行前保存。行向量约定；一头、三个允许位置、二维 value/输入/输出，
无 bias、dropout。ℓ 是给定的缩放后 logits，不重建 QK、RoPE 或上游 Norm。
x、V、Wg、Wo、目标、学习率与后续 query 反例均有明确数值；alternate 输入与边界检查写在执行源码。

- a=softmax(ℓ)，h=aV，g=sigmoid(xWg)，r=h⊙g，y=rWo。
- 固定 h/g 时比较无门、G1 逐通道、整头标量与移到 Wo 后的路径。移位只用相同数值构造反例，
  不冒充论文 G5 模型的实测。所有通道同一个标量且无 bias 时可与投影交换；一般逐通道不成立。
- 固定门可折叠到 Wo；输入相关门在另一个 x 下不符合那一份固定折叠。未声称证明所有可能参数下都不可折叠。
- L=0.5||y−y*||²。解析反传核对 3 个 logits、6 个 value、4 个 Wg、4 个 Wo，共 17 个局部导数。
  x 固定，未核验上游 Q/K、Norm、完整骨干的导数。
- 只对 Wg 做一次 η=0.1 的 SGD；固定目标 loss 下降只是这一局部更新的结果，不是语言模型成绩。
- 饱和表保留九位有效数字；在有限实数 z 下 sigmoid 不到端点，浮点则可能舍入到端点。
- KV 反例对比后一次 query 的完整三位置与误删第 0 项。前一次输出门极小，不约束后一次门值与查询权重。
  它否定“当前门小足以保证未来缓存无用”，不模拟某个引擎的剪枝实现。

标准库 Python 3.10+，在仓库根目录执行：

    python3 artifacts/gated-attention-20261030T125431Z/check-mechanisms.py

默认重算结果，核对正文四表两值及 results.json。--preview 只输出不写；--write 仅首次创建，拒绝覆盖。
代数用 1e-12 尺度容差，中心差分步长 1e-6；导数与缓存差分字段用 1e-8；文本、整数、结构严格比较。
结果保留全部 17 项差分、完整张量、更新后权重和反例，不能只凭四舍五入后的正文判断相等。
