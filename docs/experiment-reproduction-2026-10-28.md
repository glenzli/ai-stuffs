## 实测结果与适用范围

学习实验沿用三个 seed 11/29/47、每个 1,200 次更新、batch 64、LR 0.003，以及原
模型、任务和生成设置。当前三个 seed 的训练、验证与独立测试 EM 均为 100%，
长度 6–8 外推 EM 均为 0%。旧页面快照中 seed 47 的 93.33%/91.37% 不再作为
当前结果展示；旧快照仍保存在运行前源码副本中，仅用于比较，不替代完整历史证据。

当前环境为 macOS 27.0.1 arm64、Python 3.12.13、PyTorch 2.9.0、NumPy 2.3.4、
mup 1.0.0，实验单线程运行。旧记录的系统与 Python 补丁版本不同，结果也发生了
变化；本轮没有将差异归因到单一因素。配置和拆分对照见 `result-comparison.json`。

故障实验的 115 项检查通过：真实溢出、高 LR 有限更新、符号监督旋转均被记录，
修复与正常对照的张量及最终状态相同。动态实验完成宽度扫描、54 个深度配置、
17 个噪声抽样法则及 18 个 Batch 配置；新运行直接保存恢复参考 RNG，无需借用
旧报告缺 RNG 后派生参考的说明。

分块交叉熵完成 360 个配置、2,981 次独立数值比较和有限差分核验。最大 dense/JS
差为 4.441e-16，有限差分最大误差为 4.648e-11。本轮小型 CPU 测量仍表现为分块
减少反向保存的 storage 引用，但比 dense 慢；页面改用新耗时样本。保存引用量
不等于进程内存峰值，这些 CPU 耗时也不推导 GPU 性能。

## 核验链路

`scripts/experiment-sources.mjs` 在构建替换 `dist/` 前核对完整报告、工件包及校验表
的字节数和 SHA-256；缺失或被修改会使构建失败。报告、下载包和页面来源使用同一
清单。学习页的结果摘要由完整报告生成，避免正文和交互快照各自维护测量值。

Node 核验快照的每个保留测量值均来自完整报告，并核对构建后的下载文件。
归档测试实际解压四个下载包，再用独立的 `shasum` 检查原始工件和运行时源码。
Python 从保存的权重重新计算学习的初始/最终全部拆分、全部深度探针、已选宽度
的验证/测试、Batch 最终评估及固定参数梯度；故障审计从保存张量重算损失并核对
修复状态。恢复实验已在新进程核对参数、优化器、RNG、数据位置和后续轨迹。

```sh
npm run check
npm run test:provenance
npm run test:learning
```

下载工件包并解压后，在对应的实验子目录执行：

```sh
shasum -a 256 -c SHA256SUMS
```

在解压根目录执行 `shasum -a 256 -c SOURCE-SHA256SUMS` 可核对运行时源码。
重新训练必须写入一个新目录；页面及 manifest 给出的命令沿用同一固定预算。
结构与哈希检查证明当前保存文件之间的一致性，不对任意外部导入报告作来源认证，
也不承诺跨系统逐位重现训练轨迹。

验证日志与截图保存在同一新工件目录，最终结果汇总见 `verification-summary.json`。
修改前源码另备份于 `/private/tmp/reproduced-20261028T115030Z-source-before.tar.gz`。
