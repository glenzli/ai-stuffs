## 为什么补这部分

六步路线已能连起学习过程，五项实战也有稳定入口，但后续新增的监督分母、
同预算训练、混合召回、来源过滤和填充推理等实测仍分散在专题内。
读者遇到具体症状时，需要同时知道去哪看、对照什么、结果能说明到哪，以及重跑前要准备什么。

本轮在 `deep-dive.html#verified-experiments` 增加默认折叠的实测索引，
从指南与综合自测接入。按来源清单覆盖十三组，每组提供：

- 一个可定位的工程问题、所属专题及相关页面。
- 参考对象、解释边界与运行条件。
- 从固定清单生成的完整报告、工件包和校验表，共 39 个下载链接。
- 独立重跑命令与来源清单登记命令的原文。

“十三组”指来源组，部分组包含多个实验或页面。此次未增加第十四组实验。
六步主线、五项实战和数值结果沿用既有内容。

## 搜索与静态阅读

搜索会统一大小写和全角字符，多个词需同时匹配。例如 `检索 过滤` 定位来源过滤，
`DDP` 定位完整模型更新，`padding` 定位填充与缓存。
搜索条件保存在 `verify` 参数中，刷新、返回或复制链接均可恢复。
进入 `#verified-experiments` 时自动展开入口；不启用 JavaScript 时仍可展开阅读所有卡片和来源。
动态搜索控件仅在初始化成功后显示。

内容条目由 `src/experiment-navigation.mjs` 维护；
`scripts/render-experiment-navigator.mjs` 负责与已核验来源绑定；
搜索状态由 `src/scripts/features/experiment-navigator.js` 负责。
原始数值继续由各实测页面和来源包负责，导航不复制测量值。

## 命令和环境说明的正确性修复

来源清单的 `command` 是登记的复现示例，并不等于原始进程实际使用的命令行。
现保留原文，明确标作“登记的复现命令”；独立重跑示例根据经过核对的生产脚本参数生成：

- 各组使用不同的新输出目录，读者需确认目录尚不存在。
- 训练动态示例移除 `--write-page-data`，避免直接改写已采纳的页面数据。
- 三项扩展示例增加对应的 `--only`，避免选一项却重跑全部三项。
- 保留学习实验登记的 steps、seeds、batch、学习率与线程设置。
- 未识别的脚本、参数、重复选项或复杂 shell 语法不自动改写，转为人工检查提示。

这段处理只生成说明文本，不在构建或浏览器中执行实验命令。
重跑结果仍需独立核验后另行采纳，不能仅因命令结束就替换既有证据。
来源过滤的运行环境只登记 Python 与 NumPy，现仅展示存在的环境字段，
修复此前的 `PyTorch undefined`。
