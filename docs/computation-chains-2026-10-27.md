## 计算与证据边界

- 位置页用固定六个四维输入、单头 Attention、输入残差和三类输出；无 Norm、FFN 和 dropout。其配置与训练实验的两维 block 不同，正文和报告分别声明。左 PAD 占槽但不可见，位置从有效 token 的 0 开始。
- 混合精度页使用预设梯度，并非模型训练曲线。FP16 作用于缩放后的梯度贡献，FP32 用于累积和参数写回；每两次有限更新使 scale 翻倍。该规则不代表框架默认配置，也不模拟 GPU 的全部逐算子行为。
- 恢复实验复用原反传页的完整小 block，训练全部权重及两个 RMSNorm 的缩放参数；四个样本顺序循环，输入加入明确 RNG 产生的小扰动。只有末位置监督。参数、Adam m/v/t、LR 计数、RNG 和数据游标经 JSON 保存；保存位于更新边界。
- FSDP 是明确的逻辑执行模型，不调用 FSDP2 或通信库。缓冲区账本包括参数、动量、临时完整参数、完整本地梯度和归约梯度片，假设每元素 4 B；数值计算仍为 JavaScript 双精度。不计 activation、workspace、物理缓冲区别名或真实延迟。
- MoE 固定路由 logits 和门控，不对 router 求导。容量按原 token 顺序保留，丢弃后不重归一化；参考实现使用相同丢弃规则。参数与输入梯度用有限差分核验。
- 投机概率是固定前缀上的有限分布计算。两草稿流程额外假设各位置使用相同 p/q，便于隔离验收规则；不模拟真实模型的前缀依赖和耗时。原有预设拒绝位置的流程图保留，承担缓存流程说明。

## CPU 实验

运行：

```bash
npm run lab:cpu
```

默认输出到新的 `artifacts/cpu-lab-<timestamp>/`。可通过 `-- --out-dir <新目录>` 指定目录；记录文件以独占创建方式写入，已有同名输出不会被覆盖。

命令执行连续八步基线，第三步更新后保存 checkpoint，再分别启动六个新 Node 进程恢复。运行时为 Node v22.17.1，运算为 JavaScript binary64；不下载模型或运行 GPU。

本轮记录位于 `artifacts/cpu-lab-2026-10-27-computation-chains/`，包含 checkpoint、连续基线、六种恢复轨迹和 report.json。结果为：

| 恢复方式 | 首次参数偏差 | 后续各步最大参数差 |
| --- | --- | --- |
| 完整恢复 | 无 | 0 |
| 遗漏 Adam | 第 4 步 | 0.0317175750209677 |
| 遗漏 LR 计数 | 第 4 步 | 0.014117190265575008 |
| 遗漏 RNG | 第 4 步 | 0.005145381496752449 |
| 遗漏数据游标 | 第 4 步 | 0.0275822518170466 |
| 仅恢复权重 | 第 4 步 | 0.04790816793159858 |

这些结果验证声明配置下的训练轨迹。它们不说明真实模型质量、泛化、吞吐或跨硬件逐位复现能力。保存点若恰好落在四样本循环边界，遗漏数据游标的后续样本可以相同；页面与测试保留这个反例。
