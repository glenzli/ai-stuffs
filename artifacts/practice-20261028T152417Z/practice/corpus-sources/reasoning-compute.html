01 / WHAT IS IT

CoT 怎样表示中间推理？

Chain of Thought（思维链）是模型在答案前或答案之间生成的一串中间步骤，例如先列条件、做分解、算中间值，再给结论。原始 CoT prompting 的关键是给出“问题 → 推理步骤 → 答案”的示例，让同一个模型按这种模式继续生成；提示时不需要修改权重。

对自回归模型，中间步骤和答案一样是 token。已生成的步骤进入后续上下文，下一步可以注意到这些符号，相当于获得可读取的临时记录。更多步骤也意味着更多 forward、更多 KV 和更长延迟。每一步的正确性、作用和解释忠实性，需要分别检验。

继续推导：一条推理的概率，怎样联系最终答案的概率？

同一个答案可能由多条推理得到。若采用“先采样推理、再生成答案”的固定协议，最终答案的边缘概率需要对全部可能推理求和：

一个两路径示例：模型以 0.6 的概率选到 r₁，其中目标答案概率为 0.9；其余 0.4 选到 r₂，其中目标答案概率为 0.1。最终是 0.6×0.9+0.4×0.1=0.58。只展示 r₁ 后看到的 0.9，不能代表整个采样流程有 90% 的成功率。

真实推理序列太多，通常不能显式求和。多条采样、投票、搜索或验证器选择是不同近似或决策规则；挑出“最高分一条”也不等于计算这整个求和。

02 / HOW IT IS TRAINED

CoT 监督使用哪些数据和目标？

训练记录可以写成 (问题 x，中间步骤 r，答案 a，验证结果 v)。不同算法使用其中不同字段。

01 / GENERATE

得到候选轨迹

人工解题、强教师生成、工具执行或当前策略采样。记录来源和完整上下文。

02 / VERIFY

检查答案与步骤

结果验证、可执行中间量、过程标注。最终答案和中间步骤分别检查。

03 / OPTIMIZE

选择训练信号

SFT 模仿 token；偏好比较轨迹；RL 用奖励加权策略更新。三者对轨迹的监督粒度和更新方式不同。

04 / EVALUATE

固定预算比较

新问题、相同输出预算、独立验证器；检查正确率、长度和停止行为。

方法监督与梯度具体边界
CoT SFT将推理与答案拼成 s = r ⊕ a，对选定位置的 token 做 teacher-forced 交叉熵，下方给出带 mask 的目标。先按模板区分 reasoning 与 answer；可分别加权、mask。长轨迹在全局 token 平均下权重更大，错步骤也会被模仿。
拒绝采样 + SFT教师/策略生成多条轨迹，保留通过检查者，再做监督训练。筛选改了数据分布；只留容易题、短答案或评分器喜欢的格式会产生偏差。
Outcome RL / RLVR由最后结果给标量 reward，经 advantage 和 log-prob 更新采样策略。通常不提供逐 token 的正确步骤标签。中间步骤如何得到信用取决于估计器、奖励位置与目标。
过程监督 / PRM标注中间步骤正确性，训练 process reward model；可用于搜索评分，也可参与策略训练。“步骤”切分、标注噪声和多种合法路径都要处理。过程评分需通过独立结果验证和路径对照检查。

只监督最终答案，模型会自动学到正确 CoT 吗？不保证。若中间推理 token 被 mask，它们没有直接 CE 标签，但仍可能作为后续条件产生梯度路径；若它们是离散采样得到的，仅对最终答案 CE 反传不能自动穿过采样操作，需要另一个训练设计。上下文的计算路径和产生离散 token 的采样过程，需要分别处理。

04 / INTERNAL REPRESENTATIONS

潜在推理与 J-space：模型内部发生了什么？

连续潜在空间推理

Coconut 等研究将某步 hidden state 直接作为后续输入表示，让连续状态承载中间计算。采用这种回路需要相应的训练流程和执行方式。

Anthropic 的 J-space

Anthropic 在 2026-07-06 的研究中，用 Jacobian lens 识别了一组与概念相关的内部激活模式，并将它们称为 J-space。研究者观察模型能否报告和调控这些模式，再通过干预检验它们对任务结果的影响。

观测、探针与干预

探针从激活中预测某个概念，说明相关信息可以被读出。要了解这些信息是否参与了任务计算，还可以改变激活，观察结果怎样变化，并用对照实验检查影响是否来自特定表示。

怎样读这些研究

先看研究测了哪些模型和任务，再看干预改动了什么、行为变化有多大。一次实验能解释某种表示的作用；更广的结论还需要跨模型、跨任务复现。

JEPA 的训练目标是在表示空间预测缺失部分。详见潜在空间与预测目标。

05 / EVIDENCE

怎样评估推理能力的变化？

把“最终正确”“步骤正确”“解释忠实”“成本可接受”分开评价。同题换数字、换表述、交换无关信息、移除提示线索，能测试它是否依赖表面模式；未见过的组合和时间后移任务用于检查迁移，但没有单一基准能证明所有分布上的泛化。

对可见 CoT，正确解释可以是事后合理化；没有展示某因素也不证明模型没用它。要结合受控干预和行为测试。停止训练时，应结合预先定义的任务目标、回归指标与推理成本作判断。

06 / RESEARCH COMPARISON

RL 提升了什么？先把能力定义和实验条件对齐

“第一次更容易答对”“有限预算内能解更多题”“正确答案来自正确步骤”是三个不同问题。测量它们的指标和采样协议不同，因此研究可能对同一类训练给出不同解释。比较前先核对底座、算法、任务、长度预算与验证器。

有限预算下的可用能力

极低概率的正确路径可能在实际上无法找到。即使路径支持集保持不变，提高有限预算下的成功率也有工程价值；报告预算与选择成本。

回答正确与步骤正确

最终答案可能碰巧命中，正确思路也可能在最后算错。分别标记答案、过程和可执行中间量，验证器的可靠性也要评估。

分布外能力需要新任务

换数字、组合、题族、来源或环境，控制难度后比较。训练题族内覆盖增加，不能直接外推到所有新任务。

同 k 还不等于同成本

回答长度、工具调用、评分和搜索开销都可能不同。用相同 token/时间/算力预算的曲线补充 pass@k。
