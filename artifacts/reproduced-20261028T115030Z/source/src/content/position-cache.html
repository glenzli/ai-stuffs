03 / POSITION CONTRACT

逻辑位置、张量下标和缓存槽分别记录

后缀 query 的行号从 0 开始

已有前缀长度为 P，新块第 j 个位置应看见有效 key 的位置 ≤P+j。直接用 j 裁剪完整 key 轴，会漏掉前缀偏移。每块多于一个位置时，还需阻止块内未来信息。

Padding 改变存储布局

示例用独立的有效标记屏蔽 PAD，并用逻辑位置生成旋转角度。框架的 position_ids、cache_position 与 attention_mask 有各自约定；接入具体模型时分别核验。

固定输入才能比较路径

先固定实际 token 序列，逐层比较数值，再比较 logits。如果先采样，不同随机数会产生不同后续输入，使“输出字符串相同”无法承担数值等价性检查。

频率或权重变化需要更新缓存

本例缓存依赖输入前缀、权重、位置和频率。更换这些条件后，原 K/V 不再代表同一前向路径。共享缓存还要核对模型与 adapter 版本。
