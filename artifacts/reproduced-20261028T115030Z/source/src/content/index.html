模型怎样学习：从输入走到一次更新

先给定输入和要预测的答案。输入经 tokenizer 得到 token ID，模型把它变成向量和预测， 再根据监督位置计算损失、更新参数。更新是否有效，还需要看新的输入和实际生成结果。

KEEP THESE THREE

先带走三个锚点

A

表示进入后续计算

查表向量只是输入的一站。模型还会结合上下文形成隐藏状态，再通过输出头得到预测；下一步沿这些张量看一次前向。

B

目标决定优化信号

语言模型对有效监督位置计算交叉熵，检索模型可以用正负样本构造对比目标。需要先明确目标、分母和参与计算的位置。

C

学习效果需要独立检验

训练 loss 下降以后，还要检查自由生成、独立输入和未见长度。小模型实验会展示拟合成功与长度外推失败同时出现的实际结果。
