QUANTIZATION / INTEGER LINEAR LAYER

量化线性层：整数怎样恢复为同一单位

把输入、权重、累加器和 bias 放在一起，逐项核对零点与 scale。先确认整数算术实现了声明的量化层，再比较它与原始浮点层的误差。

固定形状

X:[2,3]，W:[3,2]，bias:[2]。W8A8 使用 uint8 输入与权重、INT32 范围内累加；页面计算由 JavaScript binary64 执行。

01 / UNITS

每个数值都有自己的刻度与整数零点

校准区间包含实数零点：low=min(0,min x)，high=max(0,max x)，s=(high−low)/255，z=clip(round(−low/s),0,255)。全零时规定 s=1、z=0。整数舍入采用半数远离零；输入区间来自独立的两条校准记录，权重范围来自当前层。

输出 scale 由校准记录通过原始浮点层得到，再将量化层输出映射回 uint8。校准与展示输入分离；“输入超出校准范围”场景把展示输入放大八倍，暴露 clipping 的影响。

02 / DOT PRODUCT

怎样从原始整数点积补回零点修正？

这条 W8A8 路径用 INT32 可表达的整数进行精确累加，但输出 scale 相乘与重定标仍用实数运算。生产中的纯整数输出常把倍率转换为固定点乘数和移位；本例未模拟该逼近，其误差和舍入需要另行验证。

04 / ERROR BUDGET

权重误差小，输出误差一定也小吗？

算术一致性

恢复后的 X/W/bias 做矩阵乘，与整数累加再恢复应该一致。这个比较可发现零点、轴和单位错误。

模型近似

原始层与正确量化层允许有误差；校准输入上的小误差需要在独立任务与长尾输入上复核。

W4A16 的口径

权重用逐通道 −7…7 对称刻度；输入先舍入到 FP16 可表达值，恢复后的乘加使用 binary64。它展示权重压缩与激活舍入，不执行低位硬件 kernel。

逐通道与分组

本例的 scale 在每次点积内部固定。沿 k 分组时，各组点积需要分别乘 scale 后相加，不能把一个倍率提到整行外。
