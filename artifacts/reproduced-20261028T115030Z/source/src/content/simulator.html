HOW TO READ

模拟器里每个现象对应什么

每个点和分数都由当前参数计算得到；下方说明各指标的计算时点与含义。

01 / LOSS

损失与命中率分别衡量什么

loss 与候选概率取本步更新前；点坐标和 Top-1 命中率取更新后。命中率按原始类别检查同一批可学习 query，不受错标修改，但它仍是训练点诊断，不是 held-out 泛化评估。每类有多个相关文档，因此这里应称 Hit@1，不能当作“找回全部相关文档比例”的 Recall@1。

02 / TEMPERATURE

温度决定谁主导梯度

温度低时，最高分候选占据更大权重，难负样本会更强烈地推动几何；温度过低也可能让优化变得不稳定或只追少数样本。

03 / HARD NEGATIVES

难负样本怎样影响分离

随机负例已容易区分时，难负例可增加细粒度分离压力，但并不保证收益；降低难负比例也不必然导致坍缩。本例将同类文档排除出负例池，只通过错误正例开关注入标注噪声。

04 / LABEL NOISE

错标怎样影响向量更新

模拟器把错误正样本当成真实目标参与 softmax 与反传。可以从向量移动和命中率变化中观察错标的影响。

SCOPE

模拟中包含和省略的环节

下面列出这个二维实验覆盖的计算，以及完整训练中仍需考虑的环节。

没有

Transformer、tokenizer、contextual pooling、batch 内其它 query 的 in-batch negatives。

没有

AdamW、学习率 schedule、混合精度、梯度累积与多卡通信。

有

点积、稳定 log-sum-exp loss 与解析梯度。先按 batch 平均，再逐向量裁剪梯度范数到 4，更新后投影到范数 ≤ 2.5 的球内；这不是全模型 global norm clipping。
