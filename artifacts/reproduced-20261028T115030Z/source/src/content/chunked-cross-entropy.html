01 / SAME OBJECTIVE

把完整投影与 CE 看作同一个计算

完整路径先生成 N×V 的 logits，再计算交叉熵。本页把位置分成 T 行、词表分成 B 列，每次只生成一个 T×B 的分数块。分块改变中间值的生命周期；每个有效位置的分母仍覆盖整个词表。

FORWARD / PROJECT

生成当前分数块

读取当前 H 行与 W 行，计算 HₜWᵦᵀ，可选加 bias。

REDUCE / CAPTURE

累计全局统计

更新逐行最大值与指数和；目标所属块到达时捕获目标分数。

BACKWARD / REPLAY

重算局部概率

用保存的全词表归一化统计重建 p；对目标类别减 1。

ACCUMULATE / RETURN

归还三类梯度

dH 跨词表块累加；dW 与 db 跨位置块累加。

C=0 时平均 loss 未定义。程序返回可微零哨兵与零梯度，调用者应跳过 optimizer 更新；有 weight decay 或动量时，零梯度本身不能保证参数不变。

02 / RUNNING LSE

每个词表块怎样加入同一个分母？

每行维护 m=已访问分数的最大值、s=相对 m 的指数和。初值 m=−∞、s=0；新的更大分数出现时，先缩放已有和。目标 logit 从包含 yᵢ 的块中读取一次，不能把块内目标 ID 当作全局 ID。

为什么这个在线统计与完整 LSE 相同？

Python 保存 m 和 log s 两个 N 向量，反向使用 exp((Z−m)−log s)。这种表示与保存 LSE 等价，但避免先把很大的 m 与较小的 log s 相加再相减。目标 logit 只参与前向 loss，不需要保存给反向。

04 / RECONSTRUCT AND SUM
重建概率后，三类梯度分别累加在哪里？

    
    
局部归一化故障
每个词表块单独 softmax，会让每个块的概率质量都等于 1。全词表 Σp 变为块数量，dH/dW/db 均被改变。正确前向 loss 可以与错误反向同时出现。
dH 被覆盖故障
不同词表块都向同一 H 行送回梯度，必须用加法。如果每次写入本块结果，最终只剩最后一个词表块。这个故障保留 dW/db，有助于定位反向累加位置。

    
Python 的自定义 autograd Function 在前向和反向都显式使用 no_grad。前向只保存 H、W、可选 bias、有效标签与 m/log s；反向把 score 块原地改成概率再改成 dZ，完成当前块后释放。框架不会为每个 tile 建立隐含的反向图。本实现只支持声明的标量平均目标的一阶梯度。

    
本页把 H 与 W 当作独立求导变量，没有接入输入查表的权重绑定。若同一参数同时用于 embedding lookup 与输出投影，最终参数梯度需要把两条路径精确相加；这里只核验输出路径的 dW，不能把它标成共享权重的完整梯度。

  


  

    
05 / THREE DIFFERENT ACCOUNTS
保存引用、逻辑中间量和实际时间怎样一起看？

    
8,192 个预测位置与 131,072 个词表项，单份 FP16 logits 的逻辑大小是 8,192×131,072×2 B=2,147,483,648 B=2 GiB。这是一个张量的算术账本；dtype 转换、输入、参数、梯度和其他层仍需单独计入。

    
口径怎样获得解释范围
逻辑元素从形状计算 score 块、两个 N 统计向量、H/W/b 与梯度缓冲区；块容量至多 min(T,N)×min(B,V)。各类别分别列出。临时行向量和 GEMM 结果也存在，不能把单块容量直接称为总峰值。
保存张量引用单独一次 saved_tensors_hooks 运行，按仍被反向图引用的唯一底层 storage 计字节，视图别名只计一次。包括保存的输入与参数。没有被保存的 tile、梯度缓冲区及其他分配不在此数中；这不是 allocator 峰值、reserved 内存或 RSS。
CPU 实际时间同一固定输入，3 次预热后 12 次前向＋反向。计时区内不启用 hooks、profiler 或 dispatch 审计。包含参数有限性检查、清空 .grad 与 Python 循环。CPU 实现与 GPU kernel 的并行、SRAM、内存带宽不同。

    
分块后仍保留 H/W/b 与 dH/dW/db；主要减少需要留到反向的 N×V 中间量。反向重算每个输出分数，增加投影工作；小块也增加循环与矩阵调用开销。下面的图只画已保存运行里的测量，不把块大小公式换算成预测毫秒。

07 / AUTHOR METHOD AND SCOPE
与 Apple CCE 的机制联系与精确范围

    
Apple 的 Cut Your Losses in Large-Vocabulary Language Models 把目标分数与在线 linear-log-sum-exp 分开计算，并在反向重建局部概率。作者 GPU 实现把小块计算放在 on-chip SRAM；本页 CPU 循环在普通内存里生成 tile，复现的是目标、梯度与生命周期，不复现作者 kernel 的硬件执行或速度。

    
作者 README 区分 cce_kahan_full_c 与 cce_kahan_full_c_full_e (cce_exact)：前者取消 classifier 梯度过滤，后者进一步取消 embedding 梯度过滤。阈值过滤跳过小概率块的梯度贡献，是相对完整实数梯度的近似；论文在指定精度与训练配置下评估它。本页先保留全部贡献，浮点舍入仍由 dense/有限差分对照衡量。
