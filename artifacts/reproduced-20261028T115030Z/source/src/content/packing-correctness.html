样本打包：边界、标签与相同的梯度

同一批独立对话，可以分别计算、补齐长度，也可以放入一个长序列。沿 token、位置、可见范围和监督落点，检查改变存储布局后是否仍在优化同一个目标。

固定实验

两条多轮对话、12 类符号词表、二维单头 Attention、输入残差和输出投影。全部权重可展开；无 Norm、FFN、dropout 或真实 tokenizer。

01 / RECORDS & TEMPLATE

两条记录如何变成训练 token？

记录 A

user:      问一
assistant: 答一
user:      问二
assistant: 答二

记录 B

user:      问三 问一
assistant: 答三
user:      问二
assistant: 答二 答三

这里把每个词直接映射到固定 ID，用教学模板连接：开头一个 BOS；每轮先放 USER 或 ASSISTANT；assistant 内容后放 EOS。A 共 11 token，B 共 13 token。EOS 用作本例回答结束标记，多轮对话仍可继续；具体模型应遵循自己的模板和轮次结束符。

目标位置与预测位置相差一步

先在 token 本身标记是否监督，再让位置 t 的 logits 预测 t+1。标签列表示当前 logits 应预测的 ID，空白表示不计 loss。模板与用户内容仍可参与后续回答计算。

监督范围先于布局

可监督所有 assistant 轮次，也可只监督原记录末轮。右侧截断在模板完成后执行；“仅末轮”不会把被截断的末轮自动替换成前一轮。

04 / REFERENCE & FAILURE

用什么证据确认打包正确？

01 / ALIGN

同一目标

对齐原始样本、截断、监督标签与全局分母，允许布局和 batch 形状不同。

02 / COMPARE

前向和反向

逐有效位置比较 logits，再比较 loss、所有参数梯度和一次更新。

03 / PERTURB

独立样本不互相影响

固定参数，只改一条记录，观察另一条记录的前向结果；更新权重后则不要求保持不变。

04 / CHECK

零标签与停止标记

确认截断后还有目标；核对回答结束符参与训练的位置和推理停止规则。
