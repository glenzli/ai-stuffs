RL 参数更新：从回答概率到下一步策略

固定一批回答与奖励，沿 logits、行为概率、优势、裁剪与 KL 计算损失，再检查梯度怎样改变参数。每个中间量都能用独立自动微分复算。

小策略

三动作词表、二维固定状态特征、W:[2,3]。四个回答长 2/1/3/2；不是完整语言模型或 PPO/GRPO trainer。

01 / DECLARE THE OBJECTIVE

先确定每个 token 的权重和梯度边界

按 token 平均

所有有效 token 共用 w=1/N；长回答有更多位置，对总目标的权重更大。

按回答平均

G 个非空回答、每条长度 Tᵢ 时 w=1/(G Tᵢ)。每条回答总权重相同；这与 token 平均是不同目标。

冻结本批采样信息

动作、奖励、组内优势、old log-prob、reference 和 mask 都停止梯度。old 表示该批回答的行为策略，reference 是另一个固定的约束锚点。

固定状态的范围

四条回答和状态特征为教学输入。截断选项只改变有效位置，奖励和优势保持固定，便于隔离长度权重；真实截断奖励需要单独设计。

奖励 [1,0,0.5,1] 减组均值并除总体标准差得到优势；奖励全相同时设优势为零。屏蔽提示和填充位置，零有效 token 时跳过更新。

05 / EVIDENCE

数值正确之后，还需要什么证据？

本地测试用有限差分核对全部六个参数，独立 PyTorch 自动微分再检查不同归一化、mask、KL、故障与连续更新。真实后训练还需要采样策略版本、任务覆盖、奖励可靠性、独立能力评估和成本记录；小策略的 loss 下降不代表语言模型能力提升。
