01 / TASK CONTRACT
先固定任务、拆分和监督位置

    
内容符号为 A/B/C/D。输入 A B C 的目标是 C B A EOS；完整训练串为 BOS A B C SEP C B A EOS。SEP 位置的 logits 预测第一个答案 token，提示词与 padding 的 labels 为 −100，仅答案和 EOS 参与交叉熵。
输入与它的反向等价输入先分到同一个 group，再按长度分层拆分。默认 train/validation/test 为长度 2–5 的 405/130/139 条，长度 6–8 外推为 143 条；exact input 与 group 均不跨集。训练、验证 pilot 只用于固定预算；独立测试和外推不选择配置。

    
PAD=0BOS=1SEP=2EOS=3A/B/C/D=4/5/6/7

    
    
模型为 2 层、width 64、4 heads、101,120 参数；使用固定正弦位置编码、Pre-LayerNorm、GELU、dropout 0.1 和未绑定输出头。固定位置编码避免引入未训练的绝对位置表，但不保证学到可外推的反转算法。

  




    
03 / GENERATION AND FAILURE
teacher forcing 与真实生成各测量什么？

    
条件交叉熵
Teacher-forced loss 在正确答案前缀下计算。其 argmax 可辅助定位监督，不能计作自由生成准确率；自由生成只接收输入 prompt 和自己此前输出。
统一结束口径
所有模型题目 greedy 生成，首次预测 EOS 或共同上限 max_new_tokens=20 才停止。不会按正确答案长度停止。生成的 PAD/BOS/SEP 保留为真实位置并计为错误，训练 padding 仍排除。
独立基线
复制与常量基线利用可观察输入长度输出 EOS；常量符号仅从训练集统计。Oracle 直接实现反转规则，是算法上界。基线没有模型的 teacher-forced loss，不作为学习证据。
固定预算的失败
seed 47 训练 EM 为 93.33%，测试为 91.37%；全部 seed 长度外推 EM 为 0%，并提前结束。这些结果在完整报告保留，配置不因测试或外推失败继续调参。

    
    
完整匹配要求内容全部正确且 EOS 恰好结束在正确位置。短且尚未结束的独立轨迹标为 incomplete，实际达到上限才标 cap。该任务的同长度未见输入成功不能代表任意算法泛化，更不能外推到自然语言模型能力。
