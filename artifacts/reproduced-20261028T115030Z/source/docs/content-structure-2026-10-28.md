# 模型工程 Wiki：阅读结构优化 · 2026-10-28

## 阅读顺序与分类

指南首屏提供“从头学起”和“解决问题”两个入口。默认学习主线为：

1. 输入与监督：区分输入、向量、预测和目标。
2. 模型前向：沿 Embedding、Attention、MLP 到输出头追踪计算。
3. 损失与更新：先走下一词预测，再按需比较其他目标。
4. 学习与泛化：先观察小模型的实际生成，再看独立测试与长度外推。
5. 稳定与复现：理解保存、恢复和故障定位。
6. 系统与扩展：进入资源预算、并行和性能问题。

六步路线是建议阅读顺序，不是数学依赖或运行依赖。指南、完整路线和主线页面的
前后篇导航共用 `src/learning.mjs` 与 `scripts/render-learning.mjs`，避免分别维护顺序。
完整路线给出每一步的前置知识、自检问题和进一步阅读。

全站 61 页按主题归入“从这里开始”及八个专题：数据与表示、模型结构、训练目标与
优化、训练系统与性能、微调与后训练、生成与检索服务、评估诊断与复现、模型能力
与应用。每页只有一个目录归属；主题、入门/进阶、内容形式分别显示。
页眉与侧栏共用主题定义，页面位置与页眉当前项保持一致。
