INITIALIZATION / RESIDUAL / WIDTH TRANSFER

初始化与宽度：把坐标尺度和学习率一起核对

初始化决定前向与反向从什么尺度开始，残差与 Norm 决定尺度怎样穿过深度。宽度迁移还要明确输入、隐藏权重、readout 和 optimizer 的规则，再用未参加选择的宽度检验实际训练结果。

两组独立实验

深度实验复用反转任务的小 decoder，固定宽度 32。宽度实验使用 8→n→n→3 的固定深度 MLP、三个 seed 和作者 mup 1.0.0；每个图点来自保存的 CPU 运行。

01 / DECLARE THE SCALE

前向、反向和参数位移要分别记录

线性层的 fan-in 是每个输出求和的输入坐标数量。在独立、零均值的近似下，输出方差随 fan-in 和权重方差的乘积变化；训练后权重与激活会相关，初始化的独立性计算不能直接代替更新后的测量。

hidden 梯度是标量目标对当前中间张量的导数；参数梯度是对权重的导数，两者形状和单位不同。参数位移与坐标位移另用更新前后的差值测量。深度页记录 sequence-mean CE 的导数，宽度页记录分类 CE；初始化与更新 1／4 次的读数分开展示。

02 / AUTHOR PARAMETER RULES

μP 用一套输入、隐藏层与 readout 规则

本实验以 n₀=16 为基础宽度，m=n/n₀。输入维度 8 和类别数 3 固定；base/delta 模型只提供哪些维度随 n 变化的形状信息，不参与训练。μP 使用作者 set_base_shapes、mup.init.normal_、MuReadout 与 MuAdam；SP 使用实际 fan-in 的正态初始化和普通 Adam。

作者包首次 set_base_shapes 会把默认 readout 权重与 bias 乘 √m；本脚本随后按上表重新初始化，设置形状先于自定义初始化和 optimizer。恢复已有参数时使用 rescale_params=False，重复转换会改变模型。MuAdam 1.0.0 只对两个无限维的隐藏权重除 m；本实验 decay=0、β=(.9,.999)、ε=10⁻⁸、不裁剪。

初始 μP readout 非零且零均值时，输出可能随宽度缩小；作者将它解释为有限宽度暂态。检查重点包括更新后的各层坐标和 readout。基础宽度下两种参数化使用相同初始化、数据流和 optimizer 数值，重合是预期的。

05 / SELECT BEFORE TRANSFER

基础 LR 只由宽度 16 选择

合成任务为 8 维高斯输入，标签由固定 8→12→3 ReLU teacher 的 argmax 产生，256 条训练、128 条验证和128 条独立测试。每个候选使用 80 次 batch=32 更新。选择规则是宽度 16 的三个 seed 最终验证 CE 均值最小；宽度 32／64 的扫描只作诊断。宽度 128 在选择冻结后仅运行选定 LR，没有在该宽度搜索候选。
