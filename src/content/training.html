02 / TRAINING LOOP

训练回路：从ID 与目标到参数更新

模型先接收 token ID 或样本配对，查表得到浮点向量，再经过上下文层和输出层。 损失函数把预测与目标之间的差变成标量；反向传播求出各可训练参数的梯度，优化器据此更新查表行与其他层的权重。

训练信号

预训练的反馈来自目标与预测之间的误差。交叉熵提高正确目标的相对概率，负采样目标则鼓励正例得分更高、负例得分更低。

01

一个 causal LM batch 长什么样？

真实训练里，数据加载器会把许多样本拼成 batch。每个样本包含 token ID、目标位置和相应的 mask。

batch item 教学示例 
{
  "tokens": [103, 4821, 17, 889, 320],
  "attention_mask": [1, 1, 1, 1, 1],
  "labels":  [4821, 17, 889, 320, 77]
}

原始序列为 [103, 4821, 17, 889, 320, 77]：输入取前五个，标签取后五个。这里已在数据侧错开一格；若框架内部会 shift labels，就应传原始对齐标签，不能再错开一次。

forward pass 形状示意 
raw_ids                   # [B, T+1]
ids = raw_ids[:, :-1]      # [B, T]
labels = raw_ids[:, 1:]    # [B, T]
x = E[ids]                # [B, T, d]
h = Transformer(x, causal=True)
# RoPE 在各层 Q/K 上；绝对位置才常加到 x
logits = h @ W_out.T      # W_out [V,d]
loss = CE(logits.reshape(-1, V),
          labels.reshape(-1))

进入第一层的浮点张量是 x；它由 token ID 和当前 embedding 表共同决定。

01

输入 ID：分词后得到整数 ID，例如 17。模型据此定位 embedding 表中索引为 17 的一行。

02

查表结果：取出该行当前的 d 个参数。例如 d = 768 时，得到一个 768 维向量；后续训练会更新这些数值。

03

自动微分怎样计算梯度

反向模式自动微分从标量 loss 往回走，用每一步的局部导数相乘，得到每个参数对 loss 的敏感度。

01loss 很小或很大当前预测与目标差多少
→
02dL/dlogits抬高/压低哪些得分
→
03dL/dhhidden state 怎样改
→
04dL/dE[row]查表行怎样改
→
05optimizer.step()按学习率迈一小步
SOFTMAX + CROSS ENTROPY
\frac{\partial\mathcal L}{\partial z}=p-y

对正确类别，logit 梯度为 p−1；对每个非目标类别为 p。完整词表 softmax 因此通常给所有候选输出梯度，不需要逐个标注负例。

EMBEDDING LOOKUP
\nabla_{E_{k,:}}\mathcal L=\sum_{t:\mathrm{id}_t=k}\nabla_{x_t}\mathcal L

token k 出现三次，lookup 分支就把三个位置的梯度加回同一行。未出现的行没有 lookup 梯度，但绑定输出头时仍可能有输出梯度；历史动量与权重衰减也可能改变参数。

UPDATE
E\leftarrow E-\eta\nabla_E\mathcal L

η 是学习率。AdamW 等优化器还会结合一阶/二阶矩估计并做权重衰减；“负号”表示往降低当前损失的方向走。

梯度的形状与计算量： 对 embedding 行求导得到 d 维向量；对整个模型求导则得到与所有可训练参数同形的梯度。反向自动微分沿计算图组合局部导数，计算量通常是前向的常数倍，不需要在参数空间逐个试方向。它提供局部方向，不保证有限步更新一定降 loss 或达到全局最优。

负样本怎样变成梯度？

这里用二维向量和 logistic 负采样做真实一步 SGD。固定 query 是为了看清 context 向量往哪走。

TOY 2D / 教学投影

query / center 正样本 负样本

TARGET / 目标

提高 query 与正样本的点积，降低它与两个负样本的点积。

query · 正样本0.70应上升 ↑
query · 负样本 A0.69应下降 ↓
query · 负样本 B0.65应下降 ↓
单正样本 + 2 负样本
\mathcal L=-\log\sigma(q^\top p)-\sum_i\log\sigma(-q^\top n_i)

正例梯度为 (σ(q·p)−1)q，负例梯度为 σ(q·n)q；梯度下降的更新方向与导数相反。这里只优化点积，不保证欧氏距离按同样方向变化。
