工程框架

训练工程师的七个契约

七个方面各有对应的观测信号，可据此选择排查范围。

01 / OBJECTIVE

目标契约

模型优化的是 token、pair 还是 preference？正样本、负样本和 reference 是什么？

结合目标函数解释 loss 的变化。 02 / DATA

数据契约

唯一数据、重复、去重、tokenizer、special tokens、隔离与污染；线上 query 分布是什么？

确认输入数据的内容、分布与版本。 03 / TENSOR

张量契约

shape、mask、labels、padding、response mask、heads/KV heads、tied head 是否一致？

运行成功后，继续核对形状和 mask。 04 / RESOURCE

资源契约

权重、optimizer、activation、KV、通信与吞吐；DP/TP/PP/EP 如何组合？

测量峰值占用与等待，判断扩展条件。 05 / OPTIMIZATION

优化契约

global batch、梯度累积、LR/warmup、clip、init、precision 与异常数据。

验证梯度、更新和恢复过程的数值一致性。 06 / EVIDENCE

证据契约

held-out、切片、置信区间、污染、生成样例、发布门槛与回归集。

用独立测试与回归结果验证训练收益。 07 / ARTIFACT

工件契约

config、tokenizer、weights、optimizer、scheduler、RNG、数据游标与版本 manifest。

保存恢复状态与版本，便于复现和后续使用。

概念地图

训练工程师需要建立的概念地图

理解常见问题的原因、定位信号和可调整环节，有助于选择进一步研究的方向。

展开六个工程知识方向
DATA

清洗 → tokenizer → mixture

知道 token 密度、去重、污染和混合会改变训练分布。

MODEL

architecture → weights → shapes

看懂 QKV、Norm、FFN/MoE、GQA/MLA、参数与 KV 公式。

SYSTEM

compute → memory → communication

区分计算瓶颈、OOM、通信等待与 dataloader starvation。

OPTIMIZATION

loss → gradient → update

理解 learning rate、batch、accumulation、precision、clip 与恢复。

EVIDENCE

metric → slice → uncertainty

会设计 held-out、污染检查、配对比较与发布门禁。

OPERATIONS

artifact → rollout → monitoring

文件版本、索引重建、灰度、回滚和失败集回归。

CORE / COMPUTATION

把训练过程逐项算清楚

按计算图、数值、执行和输出四条线阅读。每页先声明简化条件，再用参考结果核验；模型质量与硬件速度另行评估。

展开计算图、数值、执行与输出的 18 个专题
1. 整层反向传播

从交叉熵穿过 Attention、RMSNorm、残差和 SwiGLU，核对每个梯度。

 2. 浮点与数值稳定性

从舍入、求和顺序到稳定 softmax，观察误差怎样产生。

 3. 分块 Attention

运行最大值、分母与加权和，逐块还原同一行输出。

 4. 多卡张量与通信

两张逻辑卡分别算什么，在哪里合并前向结果和梯度。

 5. 激活保存与重算

沿时间线追踪激活的保留、重建、使用和释放。

 6. 采样与约束解码

从 logits 到候选、概率和输出，比较 greedy、采样和搜索。

 7. 张量布局与内存

用地址、步长和共享写入区分视图与副本。

 8. 综合理解检查

自己核对数据、监督、形状、通信与缓存，再展开依据。

 9. 位置与缓存一致性

比较 RoPE、mask 和增量前向，定位第一个不同的 logits。

 10. CPU 训练与恢复实验

运行同一小模型，保存状态并在新进程恢复，核对后续参数轨迹。

 11. 样本打包与监督边界

从多轮记录走到 token、mask、logits 和相同的参数梯度。

 12. LoRA 的梯度与合并

观察 A/B 初始化、输入梯度、冻结底座与量化后的合并。

 13. 跨卡对比学习

全局负例、远端表示梯度、DDP 参数平均和累积边界。

 14. 独立框架对照

用固定 PyTorch 版本核对自动微分、更新、恢复和双进程通信。

 15. 分块反向与概率重建

保存 LSE，重建局部概率，再累计所有 Q/K/V 梯度。

 16. 全局负例的梯度缓存

分块编码、全局表示梯度、随机重放和编码器反传。

 17. 分片范数与统一裁剪

唯一拥有计数、复制参数去重、非有限梯度与协调跳步。

 18. 保存量与真实耗时

阅读 CPU 误差、张量存储引用、耗时分布及 profiler 报告。

TRAIN / REPLAY / MEASURE

从小模型的学习过程检验训练决策

先运行固定符号任务，再沿相同输入和评价口径检查生成、泛化与异常。深度、宽度、batch 和输出层各自保留独立对照，实际报告可在专题中读取。

展开 5 个学习动态与输出层专题
1. 学习、生成与泛化

比较训练前后、多个种子、独立组合和长度外推，核对恢复与缓存。

 2. 故障与确定性回放

从同 checkpoint 和输入定位数值、更新与监督的首个差异，再验证修复。

 3. 初始化与宽度迁移

分开深度和宽度，测量初始与更新后尺度，检查参数组与保留宽度。

 4. Batch 与梯度噪声

先核算固定参数的样本梯度，再比较相同消费 token 预算的真实学习曲线。

 5. 分块输出投影与交叉熵

累计稳定 LSE、重建全部梯度，分别核验精确目标、保存量和 CPU 时间。
