MODEL RELIABILITY / UNCERTAINTY

不确定性：何时回答，何时查证

一个答案可以流畅、自信、反复出现，同时缺少事实依据。把模型概率、语义一致性、校准和证据分开测量，才能决定何时回答、检索、追问或交给人工。

三个对象

生成某个 token 的概率；答案正确的概率估计；外部证据对答案的支持。它们需要各自的定义和测试。

01 / SIGNALS

模型的“自信”可能来自什么？

信号实际测量用途局限
Token log-prob / 熵给定前缀和生成协议的词表分布。观察预测集中程度、比较候选序列。同义改写、长度、模板和温度都影响数值；不能直接解释为整条答案的正确率。
口头置信度模型输出“有把握”或一个分数。作为待校准的预测特征。受指令、措辞和后训练影响，需用带可靠标签的数据检查。
语义一致性多次采样的答案含义是否一致。发现对采样扰动敏感的回答。共同误解、系统性推理错误可能稳定重复。
外部验证原文支持、数据库状态、计算或测试结果。核对特定主张或可执行结果。来源、时间、测试覆盖和判分器本身也需要检查。

讨论幻觉时，先明确是事实错误、无依据补写、引用不支持、与输入矛盾，还是推理错误。问题缺少必要信息时，可以追问；资料需要更新时，可以检索；验证成本很低时，可以计算或执行检查。风险信号帮助选择后续动作，正确性仍由任务标准决定。

筛选效果取决于分数的排序质量。提高门槛会减少回答量，但剩余错误率在有限样本上不保证逐点下降；本例也不表示任何真实模型的风险曲线。

阈值还要结合成本：错误回答、人工复核、检索和拒答各有代价。按语言、任务、长尾和高影响场景检查被放弃的人群；只报告回答部分的准确率，会遗漏覆盖损失。后训练或数据分布变化后，需要重新校准和评估。

03 / CALIBRATION

预测 80% 正确的样本，实际有多少正确？

校准比较分数与实际频率。把相近分数的样本分到一组，比较平均分数和正确率；样本越少，估计越不稳定。一个永远报总体成功率的模型可能校准良好，却无法区分哪些题更难，因此校准和区分能力要一起看。

Temperature scaling 与生成温度有什么关系？

两者都可能对 logits 除以温度，但目的不同。分类校准在独立校准集上拟合温度，再检查概率质量；生成温度改变采样分布。开放回答还需要定义答案事件和正确标签，仅把 token 分布变平并不能获得校准的事实正确率。ECE 的分箱选择、样本数量和分布变化也需报告。

Farquhar 等（Nature，2024）研究用语义熵检测对采样扰动敏感的错误生成，范围是幻觉中的一类。稳定重复错误时，熵可以很低；同义关系判断不准时，熵也可能被高估。使用时结合外部依据、任务切片和拒答代价，单独测量检出与误报。
