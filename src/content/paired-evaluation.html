配对评估：这次提升有多少不确定性

保留同一题的新旧结果，再选择独立的重采样单位。逐题差值、来源组、训练 seed 和模型选择过程决定一个提升数字能支持什么判断。

估计对象

固定两个模型、固定一个训练 seed 的逐题平均分差。分数为 0…1，差值显示为百分点；重采样不会覆盖全部训练与部署不确定性。

01 / SAME QUESTIONS

为什么新旧分数必须一起抽样？

逐题 bootstrap 在 n 行中有放回抽 n 行，每次重算差值。若一篇文档产生多道题，题目可能相关，应以文档为独立单位：有放回抽相同数量的文档，每次携带整个组，再以抽到的全部题目为分母。

本例始终估计逐题平均。组大小不等时，不能先平均每组再等权平均，否则换成了“每组平均”的目标。按组抽样还要求来源组之间近似独立，并且这些组能代表要外推的目标分布；相关结构不清楚时不能靠一个开关解决。

03 / INTERPRET THE RESULT

区间、置换和实际收益各回答什么？

百分位区间

排序重采样差值后取 2.5% 与 97.5% 分位，分位采用相邻次序统计的线性插值。此方法用于演示；小样本、偏态或边界统计的覆盖率需要检查，不能保证恰好 95%。

精确配对置换

最多 16 个单位时，穷举每单位新旧标签共同交换的 2ᵐ 种组合，计算 |差值| 不小于观察值的比例。按组时整组共同交换；需要零假设下标签交换性，不能把任意观察数据都当作随机实验。

训练 seed 单独展示

不同 seed 的模型是不同实验。这里逐个 seed 计算区间，旁边展示其他 seed 的点估计，不把它们混成更多独立题目；跨 seed 结论还需一致任务集与适合的层次设计。

退化与空数据

空数据、缺失配对、非法分数和同 seed 重复题目会被拒绝。只有一个独立单位，或所有差值相同，会产生退化区间；这不证明部署表现没有不确定性。

区间下界高于事先约定的最小收益，只构成一项证据。还要检查困难切片、误差严重性、成本与独立测试；p 值不表示“新模型更好的概率”，区间包含零也不等于证明两模型等效。

04 / REPEATED SELECTION

反复选最高分，会把验证噪声选进去吗？

下面所有候选真实成功率都固定为 60%。每次从独立的 40 题验证结果中选最高分，再读取独立的 40 题测试结果。候选越多，验证最高分更容易偏高；这是一项理想化模拟，真实 checkpoint 常共享错误，独立性程度需要另查。

模拟对验证与测试使用分开的固定伪随机流，验证并列时选择最早候选。真实训练应预先固定选择规则、评估频率与收益门槛，最终独立测试保留到选择完成后。

05 / LOCAL RESULTS

怎样把自己的逐题结果带进来？

{
  "schema": 1,
  "rows": [
    {"id":"q1", "group":"document-1", "seed":"11", "old":0.4, "new":0.6},
    {"id":"q2", "group":"document-2", "seed":"11", "old":0.8, "new":0.7}
  ]
}

文件上限 1 MiB、最多 2,000 行。id/group 必须是非空字符串，seed 可省略并归入 default；old/new 必须是 0…1 的有限数字。组 ID 应反映共享文档、会话或题族等相关单位，不能为了更好看的区间随意修改。文件只在本地浏览器读取，失败时清除旧结果。
