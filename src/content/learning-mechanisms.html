上下文学习：固定权重怎样利用新示例

输入改变后，激活、注意力和后续预测随之改变。从一个模式复制电路出发，再看研究者怎样定位特征、设计干预、检验内部机制。

前向计算也能适应

训练塑造可复用的计算规则；上下文给出本次任务的线索和示例。一次普通前向调用不需要再运行 optimizer。

01 / CONDITIONING

“临时学会”，可以指哪些变化？

识别本次要做的任务

示例提示输出格式、标签含义或任务类型，模型选择已学到的行为。换标签、换格式和换示例顺序可以检查这种依赖。

利用本次输入提供的关系

上下文中出现 A→B 的对应，模型可在后续 A 出现时利用它。输入内关系的使用与训练期间学到的先验共同影响答案。

中间状态保存临时信息

残差流与 KV 携带当前前缀的状态。改变示例通常需要重算受影响的前缀，不能继续沿用不同内容对应的 KV。

实验要控制哪些变量

示例内容、标签、顺序、相似度、数量和长度；固定模型与采样协议。例子更多可能带来干扰或超出有效上下文范围。

上下文学习包含多种现象：从简单重复模式到 few-shot 任务适应。不同研究使用“序列后半段 loss 改善”“新标签任务准确率”等不同定义，阅读结论时先看实验测的是什么。

02 / INDUCTION

A 后面曾跟着 B，再看到 A 时怎样找到 B？

01 / PREVIOUS TOKEN

写入前一项信息

02 / MATCH

用当前 A 匹配

后面出现 A 时，查询寻找“前一个 token 为 A”的历史位置。

03 / COPY

读取那个位置的内容

匹配到的位置保存 B，输出路径把 B 的 logit 提高。

03 / FEATURES

一个维度或神经元，对应一个概念吗？

内部表示可以在多个维度上共同编码一个特征，一个神经元也可能对多个模式响应。Superposition 研究用玩具网络分析：稀疏特征可能通过非正交方向共享有限表示空间，代价是干扰。这是关于编码方式的模型与证据，不能据此给真实模型每个坐标指定固定语义。

特征可解释性需要样本支持

查看高激活样本、低激活对照、不同语言和上下文。一个简洁名称只是解释假设，需检查误触发与遗漏。

重构误差影响后续结论

SAE 没重构出的信息可能仍对行为重要。更稀疏、更容易命名和更忠实地保留原计算之间，需要用任务结果衡量。

特征拆分与吸收

字典大小和训练目标可能把一个模式拆成多个特征，或让多个模式混在一起。不同训练得到的特征 ID 不能直接当成天然的概念编号。

从特征走向路径

找到某个激活后，还要追踪它通过哪些层和投影影响输出。Circuit tracing 尝试构建局部可读的计算关系，并以干预检验部分关系。

04 / EVIDENCE

探针、消融和激活替换，各能支持什么结论？

方法操作提供的证据需要控制
线性探针从内部状态预测标签。信息可被读出。标签泄漏、探针容量、泛化；读得出还需检验原模型是否使用。
消融删去或替换指定激活/路径。该干预下行为对部件的依赖。零值可能分布外，替换基线与冗余路径会改变结论。
Activation patching在干净/扰动运行间移植某处激活。某状态能否恢复或改变结果。输入对照、层位置、替换范围、下游混合与多重选择。
路径追踪结合特征与跨层连接建局部解释。可检验的计算路径假设。替代模型的保真度、未解释计算、任务范围及复现。

Anthropic 的 2025 年 circuit tracing 工作展示了特定任务上的路径分析和干预。报告一个内部机制时，写清楚模型版本、输入集合、干预方法和效应大小；可见 CoT、探针标签和因果计算路径应分别检验。
