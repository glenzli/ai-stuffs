TRAINING ENGINEERING / OPTIMIZATION

优化与稳定性：梯度怎样变成更新

梯度回答损失对参数的局部敏感度，优化器还要结合历史状态、学习率和正则决定实际位移。把这几步拆开，才能解释为什么梯度很大却没走远，或当前梯度为零，参数仍在变化。

前置知识

已理解交叉熵与反向传播。本页负责更新规则、初始化和稳定性；多卡归一化的正确性在独立专题中推导。

01 / UPDATE RULE

AdamW 的每个状态在做什么？

m 是梯度的指数移动平均；v 对平方梯度做指数移动平均，估计未中心化的二阶矩，用于调整各参数的更新尺度。偏差校正补偿零初始化的早期收缩；ε 避免分母过小，也可能影响极小梯度的行为。最后一项是与梯度自适应缩放解耦的权重衰减。

因此更新未必与当前 −g 同向：历史动量可能还在推旧方向。全局 η、batch、损失尺度、ε、初始化与模型结构仍需要一起调节。把 L2 项直接加到 loss 后进入 Adam 的矩估计，通常不等于解耦权重衰减。

量要观察什么解释时的条件
gradient norm裁剪前/后、unscale 前/后、全局或逐层、有效 token 归一化口径。结合训练阶段和 loss 归一化方式判断梯度大小。
update norm实际 θafter−θbefore，包含优化器与衰减；与参数范数的比例。相同学习率不意味着所有层走相同比例；零初始化张量的相对比值无意义。
m / v 状态是否恢复、极端值是否长期残留、不同参数组的配置。复现下一步更新，还需相同的矩状态、学习率和 step。
验证指标相同数据版本、长度和采样协议下的趋势及方差。随机 minibatch loss 会波动；泛化表现应在固定验证分布上检查。

03 / INITIALIZATION

为什么训练开始前就要关心数值尺度？

打破对称，保持可传播尺度

相同单元若完全对称初始化可能收到相同更新。随机权重需要结合 fan-in/out 与激活设置尺度，避免层层放大或衰减。某些残差分支的零初始化是有意设计，初始化应按各模块的结构分别选择。

残差也会累积方差

pre-norm 给残差主干短路径，但不保证任意深度或学习率稳定。残差缩放、输出投影初始化、Q/K 范数和 logits 动态范围都应随配方检查。

Warmup 是过渡阶段

学习率从小到大，让早期参数、激活和优化器状态逐步适应。标签和 mask 的正确性仍需单独检查；时长应明确以更新步、样本还是 token 计。

小模型调参怎样迁移

μP 按参数类别和宽度缩放初始化/学习率等，让某些超参数更可跨宽度迁移。不同参数类别采用不同的缩放规则；跨深度、数据、序列长度或 optimizer 时，先做坐标/尺度检查和中间规模验证。

增大 batch 通常减少单次梯度的抽样噪声，却不意味着按比例放大学习率永远成立。训练 token 相同也可能有不同更新次数；warmup/decay 用 step 还是 token 计都会改变轨迹。是否值得改 batch，需要同预算验证，同时比较验证质量、更新次数和计算成本。

05 / MATRIX GEOMETRY

Muon 怎样利用更新矩阵的结构？

AdamW 用逐元素历史矩调整更新尺度；Muon 对选定矩阵的梯度动量作近似正交化，再配合更新尺度和权重衰减。要理解这种差别，可以先看一个满秩方阵的精确极分解方向，再回到实际算法。

同一个 2×2 矩阵的三种方向

已知 SVD · 全部归一到相同 Frobenius 范数

M=R(30°)·diag(σ₁,1)·R(20°)ᵀ，旋转保持不变。逐元素一列使用首步、零历史 AdamW 梯度项 M/(|M|+10⁻⁸)，未计衰减。

位置原始 MM 归一方向逐元素方向极分解方向

每个方向都除以自身 Frobenius 范数，显示数值未乘下降方向的负号。极分解原始 Q 的奇异值为 1；归一显示后为 1/√2。本例只比较方向，不代表训练速度或长期优化轨迹。

矩阵方向与坐标尺度

改变 σ₁/σ₂ 会改变原始更新在不同奇异方向的强度。保持 U/V 不变时精确 Q 不变；逐元素缩放依赖坐标中的元素值，通常得到另一方向。

尺度仍需匹配

不同形状的矩阵正交化后，每元素更新 RMS 不同。学习率、矩阵形状、权重衰减与更新缩放一起影响实际位移；把方向归一只是本例的比较约定。

参数组需要分别指定

报告和实现常把适用的隐藏层矩阵交给 Muon，其他参数由 AdamW 等方式更新。向量、embedding、输出头、共享权重与张量 reshape 的处理需查看具体版本。

分布式结构也有影响

任意把矩阵切成几块后分别正交化，通常不同于整矩阵处理。检查分片维度、通信、重组、精度和状态恢复，再比较端到端成本。

《Muon is Scalable for LLM Training》（2025）报告了权重衰减、更新尺度与分布式实现的实验。其效率结论依赖模型、数据、预算与调参协议；评估替换时同时看质量曲线、step time、显存、通信和数值稳定性。

06 / SCHEDULE & READOUT

WSD 与 checkpoint 平均：训练终点怎样读出来？

Warmup–Stable–Decay（WSD）把学习率分成升温、稳定与衰减三段。稳定阶段的单个 checkpoint 可能波动；除直接评估它，还可以按明确窗口与系数平均相邻权重，再独立评估平均结果。学习率日程决定训练轨迹，参数平均决定另一份读出工件，两者分别保存。

同一条二维更新轨迹，保留有利与不利的结果

固定初值 [1,−0.6]，每步使用下式梯度；扰动 ξ 在 [0.6,−0.8] 与 [−0.6,0.8] 间交替。诊断函数 F 只用于这组二次函数例子的比较，不是语言模型验证分数。

在计算结果前就固定读出步 8 与 12，各取包含当前步的最近四份参数；除了等权平均，再检查从旧到新 1:2:3:4 的教学系数。不按结果挑窗口，也不把这组系数称为作者的 decay emulation。

为什么不能把参数平均直接叫成集成或原轨迹恢复？

取 fθ(x)=(θx)²、x=1，参数 −1 与 1 都输出 1；先平均参数得到 0，输出却为 0，而两个输出的平均仍为 1。这个反例说明两项操作不能普遍互换，不否定相邻训练 checkpoint 的用途。

想从平均权重继续训练，还要指定学习率步号、优化器状态、随机状态和数据游标。它是新定义的起点；仅有平均参数不能证明恢复了某条原始训练轨迹。本地脚本也比较同一平均参数在“接第 9 步”和“重启第 1 步”下的下一次更新。
