MODERN AI / GENERATION

自回归、扩散与潜在空间

Transformer 描述网络怎样计算；自回归和扩散描述怎样定义生成分布与学习目标。相同骨干可以服务不同目标，token 也不一定代表文字。

先分四个层次

表示单位 → 网络结构 → 训练目标 → 采样算法。按这四层查看模型，便于定位每项改进的作用。

01 / AUTOREGRESSION

自回归做了什么：把联合分布拆成条件预测

概率链式分解本身是恒等式。工程选择是用同一模型近似每个条件分布，并以因果 mask 阻止位置偷看将要预测的 token。每个位置的 hidden state 投到词表 logits，softmax 给下一 token 分布。多层网络将可见上下文组织成特征，用于估计这个条件分布。

训练可以并行，采样通常串行。训练已知真实序列，用 teacher forcing 一次计算各位置，但因果 mask 仍在。生成时未知后续 token，只能先采样一个，再把它作为下一轮输入。teacher forcing 指训练时使用真实前缀；teacher model 则指提供监督信号的模型。

训练前缀来自数据，生成前缀包含模型自己的错误，这种分布差异会使偏差累积。自生成轨迹训练、搜索与验证可以用于研究这类偏差，各自效果需要单独评估。KV Cache 复用过去位置的状态，减少重复计算，并不取消这种条件依赖。

02 / STATE TRANSITIONS

两种生成过程：追加一个位置，或修改一组位置

生成状态对照

文本和状态顺序均为预设，用于展示两种生成过程的依赖关系。离散去噪算法的揭示/重遮策略不统一；不能由这里的步数推出速度比。

03 / DIFFUSION

扩散：训练时制造噪声，生成时逐步恢复

01 / CLEAN DATA

取干净样本 x₀

可以是像素，也可以是图像编码器压缩出的 latent；先明确数据空间。

02 / CORRUPT

抽时间 t 和噪声 ε

按已知日程构造 xₜ，模型同时接收 t 与文本等条件 c。

03 / PREDICT

学习去噪目标

预测噪声、干净数据、score 或其他参数化；目标决定损失与采样公式。

04 / SAMPLE

从噪声开始迭代

用学到的预测和求解器逐步更新状态，最后解码成图像或其他输出。

训练无需每条样本完整跑一次去噪链：可直接随机抽 t 构造带噪输入。采样才要执行多个状态更新；具体步数和日程由采样器决定。上式采用常见的简化噪声预测目标；其他配方可能使用不同权重或参数化。

DiT 用 Transformer 构建去噪网络：Transformer 提供网络骨干，扩散定义训练目标与采样过程。潜在扩散把去噪放在压缩后的连续表示中，减少计算，但编码器重建能力与压缩也会限制细节。

路线训练对象推理状态需要核对
连续扩散已知噪声过程上的去噪/score 估计。连续 xₜ 按反向过程或求解器更新。噪声日程、预测参数化、条件引导、采样步数。
Flow Matching为噪声到数据的概率路径学习速度场 vθ(x,t)。解 ODE 等动力系统，从初始分布输送到目标分布。路径、时间参数与求解器；与扩散有联系，但不能直接混用损失公式。
离散扩散语言模型按遮罩/离散破坏过程恢复 token，例如 masked diffusion。多个待恢复位置可并行预测，也可按块推进。位置何时确定、是否重遮、训练权重、缓存可否复用；离散破坏过程需与 token 表示匹配。
自回归语言模型真实前缀上的下一 token 交叉熵。确定前缀逐步增长，标准生成可复用 KV。停止规则、采样温度、上下文与 KV、长程错误累积。

比较生成速度时：要比较每步实际工作量、总步数、缓存、长度、batch 和质量目标。扩散若每轮重算整段序列，也有成本；自回归可通过投机解码一次验证多个位置。必须在相同任务和硬件协议下比较。

04 / LATENT REPRESENTATIONS

Latent space、JEPA 与 J-space 分别指什么？

潜在空间：模型的内部表示

hidden state、VAE latent、句向量都属于潜在表示。理解一种表示，要看它怎样从输入得到、用什么目标训练，以及后续模块怎样使用它。

JEPA：在表示空间里做预测

上下文编码器和 predictor 根据可见区域，预测缺失区域的表示。I-JEPA 将这个目标用于图像；目标分支通常采用 stop-gradient、EMA 等设计，训练还要处理表示坍缩。

J-space：与概念相关的激活模式

Anthropic 把研究中识别出的一组内部激活模式称为 J-space。这些模式与特定概念有关。CoT 专题介绍了它们的识别方法、干预实验和研究结论。

潜在推理：让连续状态参与下一步计算

模型把中间连续状态反馈到后续步骤，在内部迭代计算。训练目标、状态更新方式和停止策略决定这套过程怎样运行；实验要比较计算成本和新任务上的表现。

CoT、J-space 与内部表示多模态输入与输出自回归的 KV 账本
