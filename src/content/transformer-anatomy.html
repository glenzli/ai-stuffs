ARCHITECTURE / WEIGHTS

Transformer 权重：层、矩阵与参数量

一个 decoder block 包含 Q/K/V/O 投影、SwiGLU 的 gate/up/down、两层归一化与残差； 堆叠 L 次后再加 embedding、final norm 与 LM head。MoE 则把 MLP 扩成 router 与多个专家。

本页的计数约定

忽略 bias、并行分片与 padding，按 BF16 权重和常见无偏置 decoder 计数。真实模型卡若含 bias、QK-Norm、输出门、共享专家等，需要加回对应张量；下方 Gated Attention 的新增投影不自动计入计算器。

残差为什么关键

Attention 和 MLP 的输出作为增量加到 residual stream 上。深层网络因此有可传播的梯度短路径，也让每层可以局部改写信息。RMSNorm 的缩放参数也属于权重；残差加法本身没有可训练矩阵。

输出变小，不等于可以删除旧 K/V

固定 logits 与 V 时，输出门不会重分配 softmax 权重。论文 §4.3 的 attention-sink 减少来自训练后模型的实测，不能从一次乘法推出注意力图已变化。门值接近零也不是显式 top-k、结构化稀疏或自动跳过 SDPA 的执行指令。

05 / LEARNING TO ROUTE

MoE 的路由离散，梯度从哪里来？

Top-k 在排名切换处会产生离散变化。常规反传固定本次选中的集合，沿集合内的连续计算求导。已选专家的输出影响 loss，其参数和输入可收到梯度；router 则可能通过门控权重及辅助目标得到梯度。未选专家在当前 token 上没有任务分支梯度，但可能被 batch 中其他 token 选中。

门控权重如何归一化很关键。若使用完整 softmax 的 pₑ，选中权重仍受全部 logits 的分母影响；若只对选中的 logits 重新归一化，未选 logits 通常不从这个门控分支获梯度。特别是 top-1 后再归一成常数 1，任务 loss 不会经该常数给 router 学习信号，需其他设计。Switch 的门控保留选中概率，其他 MoE 实现需按各自的门控定义分析梯度路径。

问题机制/处理应查看的证据
少数专家垄断辅助均衡 loss、路由 bias 或其他负载控制；用于稳定专家容量和调度，均衡程度由具体目标与系数控制。逐层/逐专家 token 占比、router 概率、训练阶段和最忙 rank。
专家容量溢出常见估算 capacity≈ceil(capacity_factor·tokens·k/experts)。实现可丢弃该专家分支、重路由、padding 或使用 dropless 调度。实际接收/丢弃数量、残差绕行语义、峰值和各 expert 的 GEMM 形状。
数值不稳定router logits 的精度、初始化、logit 正则和梯度处理按配方决定。logit/entropy 分布、非有限值、路由变化、aux/task loss 比例。
“专家”是否专业化路由按语言/领域聚集可能只是相关性；专家序号不天然对应人类定义的技能。受控路由/消融后的性能、跨数据的行为和实际任务贡献，用这些结果判断专家的实际贡献。

总 loss 中的任务项与均衡项可能竞争：过强的均衡压力影响任务学习，过弱可能造成专家饥饿和容量溢出。DeepSeek-V3 等具体配方还采用不同的负载控制组合，需读相应报告。即使 load 很均匀，通信、专家小矩阵与数据布局也可能成为瓶颈。

为什么本轮计数不能倒过来决定同一序列的前面位置？

保持前缀分数 [0.6,0.5] 不变。若后面三个 token 都偏向 E0，先统计整条序列再给前缀重路由，γ=0.2 会把前缀改选为 E1；把后面三个 token 改为偏向 E1，前缀又会选 E0。这是明确构造的错误两遍协议：同一前缀读到了未来负载。正确回放先使用已确定的历史 bias，当前计数只影响下一次；脚本同时核对这两种路径。

EXECUTION / DISPATCH & COMBINE

Token 怎样到达专家，再回到原位置？

Top-2 会让一个 token 产生两条专家分支。执行器按目标设备和专家排列这些分支，计算后根据原 token ID 汇合，再乘门控权重求和。排列索引必须在发送与返回两侧保持一致。

四个输入 token 分属两张逻辑卡：R0 持有 T0/T1 与 E0/E1，R1 持有 T2/T3 与 E2/E3。专家均为 2×2 线性层，路由 logits 固定；Top-2 中的两项单独 softmax，得到门控权重。该实验追踪专家输出、参数梯度与输入梯度，不对固定 router 求导。

残差、Norm 与权重的边界

这些最容易在“层数”和“参数数”里被忽略。

残差

无权重，但有跨层信息通道

x + f(x) 里没有额外的 d×d 矩阵；残差让深层 block 学习增量，并提供梯度短路径。

RMSNorm

每个维度一个缩放参数

相对 LayerNorm 少了去均值；权重通常是 d 个数。QK-Norm 还会在 head 维度增加小向量。

SwiGLU

比 plain MLP 多一组投影

gate、up、down 三矩阵。即使 FFN width 降低，参数也可能高于传统 2d·4d 两层 MLP。

Embedding

查表行与输出头可能绑定

输入表 V×d 与 LM head d×V 可能共享；tied 省参数但让输入/输出统计耦合。

这些矩阵的梯度怎样计算Attention 分块执行把矩阵拆到两张卡
